# CLI Task Tracker

Консольное приложение для управления персональными задачами на чистом Python с персистентным хранением в JSON.

## Особенности
- Добавление одной или нескольких задач одновременно (через запятую).
- Просмотр списка задач с динамическим форматированием и статусом выполнения.
- Отметка выполнения и удаление задач по идентификатору (`task_id`).
- Автоматическое сохранение состояния в локальный файл `tasks.json`.
- Обработка исключений при повреждении файла и некорректном вводе пользователя.

## Стек технологий
- Python 3.10+
- Стандартная библиотека: `json`, `os`

## Запуск
```bash
python main.py
